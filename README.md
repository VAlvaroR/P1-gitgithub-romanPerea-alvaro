# Rutas de Andalucía

Aplicación web sencilla que presenta una selección de rutas naturales y culturales por
Andalucía. Permite filtrar las propuestas por categoría y marcar rutas como favoritas.

![Ilustración de un paisaje de Andalucía](img/paisaje-andalucia.svg)

## Autoría

**Autor/a:** Álvaro Román Perea

## Tecnologías utilizadas

- HTML5 para la estructura y el contenido.
- CSS3 para el diseño adaptable.
- JavaScript para el filtrado y la selección de favoritos.

## Estructura del proyecto

| Ruta | Contenido |
| --- | --- |
| `index.html` | Página principal de la aplicación |
| `css/styles.css` | Estilos y diseño adaptable |
| `js/app.js` | Comportamiento interactivo |
| `img/` | Recursos gráficos del proyecto |

## Cómo ejecutar el proyecto

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Abre `index.html` en un navegador web.

No necesita instalación ni dependencias externas. También puedes utilizar la extensión
Live Server de Visual Studio Code:

```text
Clic derecho sobre index.html → Open with Live Server
```

## Funcionalidades actuales

- Navegación entre las secciones de la página.
- Filtrado de rutas por categoría.
- Marcado de rutas favoritas.
- Recuento automático de favoritos.
- Diseño adaptable a distintos tamaños de pantalla.
